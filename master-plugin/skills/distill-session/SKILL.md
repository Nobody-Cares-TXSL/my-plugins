# distill-session — 会话摩擦蒸馏

复盘当前会话，把调用插件时遇到的摩擦提炼成可执行的优化清单。

## 输入与工具

- Claude Code CLI：从 `$ARGUMENTS` 读取可选聚焦范围；复盘当前会话上下文；用 Read、Bash 取证；用 AskUserQuestion 确认修复项。
- Codex：从用户消息读取范围，不依赖 `$ARGUMENTS` 自动展开；使用当前环境提供的读写与命令执行工具；确认使用支持审批的工具或直接在对话中询问，没有回复就等待，不将默认选项或超时视为同意。

## 核心判据：摩擦的三方归类

会话里的摩擦**不等于插件问题**。必须归类，否则会把模型或环境的账算到插件头上，改错方向。

| 类型 | 特征 | 例 | 处理 |
|------|------|-----|------|
| **插件问题** | 脚本行为错、文档与实现不符、配置缺失、路径失效 | 脚本误删链接、文档版本号过期、缺步骤 | 进入优化清单 |
| **模型问题** | agent 输出格式错、理解偏差、幻觉、猜测参数 | 工具调用格式残缺、凭空编参数值 | 只报告，不改插件 |
| **环境问题** | 外部依赖故障、网络、版本冲突 | 镜像源 403、依赖跨大版本不兼容 | 只报告，可能需改配置 |

归类依据必须是**证据**（报错原文、脚本行号、实测结果），不接受主观感受。

## 执行流程

### 1. 收集摩擦

从当前会话上下文提取摩擦点：

- 用户明确的抱怨、纠正、困惑（「又错了」「不对」「怎么又」「为什么」）
- 工具调用失败、报错、重试
- 用户重复解释同一件事
- 被迫手工绕过（本该插件完成的事，用户自己做了）

会话被压缩过、细节丢失时，从转录补：

```bash
# 当前会话转录（${CLAUDE_SESSION_ID} 由 Claude Code 注入）
rg -n '<关键词>' ~/.claude/projects/*/${CLAUDE_SESSION_ID}.jsonl
```

> 转录里 `type: "user"` 不等于用户发言：需排除 `isMeta: true` 与工具结果（`content` 为 tool_result）。

### 2. 三方归类

逐条归类，每条附证据。归为模型/环境问题的不进优化清单。

### 3. 报告清单

输出「摩擦 → 归类 → 证据 → 建议」表，插件问题排最前。

### 4. 询问是否修

用 AskUserQuestion 让用户勾选要修的项。**不自动修**——归类可能有误，用户最清楚实际影响。

### 5. 修复（走证据优先流程）

对选中的项：

1. **取证** — `rg -c`、`wc -l`、`git log` 确认问题真实存在
2. **证伪** — 查运行日志、实测一次、对照测试，排除伪问题（可能上次已修）
3. **分级** — 零风险项（结果不变）直接做；行为变更项先确认
4. **验证** — 每项改完立刻 `bash -n` + 实测
5. **收尾** — 同步文档 → 双清单 bump 版本 → 提交推送 → 更新本地

收尾约定见 `../update-my-plugins/SKILL.md`。

## 输出格式

```
| # | 摩擦（原话/现象） | 归类 | 证据 | 建议 |
|---|------------------|------|------|------|
| 1 | 「find-skills 没了」 | 插件 | update-opencli.sh:59 差集未限定域 | 限定 opencli 生态 |
| 2 | 「是不是又打断了」 | 模型 | 工具调用格式残缺 | 无需改插件 |
| 3 | 「清华源装不上」 | 环境 | HTTP 403 | 换镜像源 |
```

## 注意

- 归为**模型/环境问题的不改插件**，只报告。
- 插件问题也要先证伪——可能上次已修复，或查证后发现机制正常。
- 只碰摩擦直接指向的代码，不做超范围改动。
