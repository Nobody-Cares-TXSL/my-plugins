# 代码解释

解释用户指定的代码，用中文说明，保留技术术语原文。

## 输入与工具

- Claude Code CLI：使用技能调用中的 `$ARGUMENTS`、选中的代码或用户给出的文件位置。
- Codex：使用用户消息中的代码片段、文件路径、行号或编辑器提供的选择上下文，不依赖 `$ARGUMENTS` 自动展开。
- 缺少明确的代码范围时询问用户，不自行选取整个仓库。
- 有文件位置时先读取对应源码，再按需查看 imports、类型和直接相关的调用方；粘贴片段没有来源时不要编造路径或行号。
- Claude Code CLI 优先使用 Read、Grep、Glob；Codex 使用当前环境提供的文件读取和搜索工具。复杂探索仅在需要且已获授权时使用可用的子代理工具，不依赖固定工具名称。

## 执行流程

- 按数据流和控制流解释，不按代码物理位置逐行复述。
- 覆盖选中范围内的全部执行路径：条件分支、fallback、异常处理、边界检查、循环终止条件和提前返回。
- 每一步说明输入、发生的操作及结果；分支写清条件和各条路径的去向。
- 复杂逻辑使用编号步骤和缩进子步骤；简单代码直接说明。
- 标注核实过的 `file:line`。Codex 中使用绝对路径文件链接，如 `[app.py](/absolute/path/app.py:12)`；Claude Code CLI 使用其支持的文件位置引用。

## 库函数

只说明代码直接调用的第三方库或标准库函数，不展开库内部实现，不解释语言语法或项目自定义函数，除非用户要求。

每个函数简述来源、作用、关键参数和返回值。参数具有有限枚举值时，逐项说明各值的含义，不只罗列名称。

优先根据本地依赖版本、类型声明和文档核实行为。需要查外部资料时使用当前可用的搜索能力和官方文档；无法核实的版本差异或动态行为明确标为不确定，不猜测。

## 输出

按需组织为：代码概要、执行流程、关键细节、涉及的库函数。说明副作用、边界条件和明显错误；短片段可合并这些部分，避免空标题。

只解释代码。发现明显 bug 时指出位置和影响，未经用户要求不修改或重构源码。
